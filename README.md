
# LostLink

Website pencarian barang hilang dan temuan di lingkungan sekolah.

## Teknologi

- Frontend: React, TypeScript, Tailwind CSS
- Backend: NestJS, TypeScript
- Database: PostgreSQL
- ORM: Prisma

## Struktur Project

- `frontend/` — aplikasi antarmuka pengguna
- `backend/` — API dan logika backend

Tahap awal: persiapan struktur project.
